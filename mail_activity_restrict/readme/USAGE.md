To use this module:

1. Go to Activity Types.
2. Open the activity type you want to protect.
3. Enable "Restrict Write to Assigned User".
4. Save.

From now on, only the assigned user sees the buttons to edit, cancel or
complete activities of this type.

Good to know:

- Anyone can still create such an activity and assign it to somebody else.
- The buttons are only hidden. Users who are allowed to change the activity
  by the standard Odoo rules can still do so outside of the chatter.
- If no user is assigned, no restriction is applied.
